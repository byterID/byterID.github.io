# План сайта-визитки

Утверждено с владельцем 14.11.2026. Тексты лежат в `content.md`, факты в остальных файлах папки.

## Цель

Главный читатель: работодатель, который ищет junior DevOps или backend-инженера. Сайт показывает DevOps на pet-проекте и backend как подтверждённый коммерческий опыт. Внизу короткий блок про фриланс для малого бизнеса. Курсовые и дипломы на сайт не выносятся.

## Технологии

- Next.js (App Router) + Tailwind CSS + framer-motion, как в референсе.
- Статический экспорт: `output: 'export'` в `next.config`. Next.js не оптимизирует картинки при статическом экспорте, поэтому `images: { unoptimized: true }`, а скриншоты сразу кладём в WebP шириной около 1600 px.
- Шрифт Raleway через `next/font/google`.
- Дизайн повторяет референс (см. `reference-design.md`): тёмный фон `#0A0A0A`, карточки `#1A1A1A`, акцент `#3B82F6`, фоновая сетка 32 px, плавающее меню-пилюля, кнопки с шиммером, появление блоков через opacity и blur. Чужие тексты, фото и имена не переносим.
- При `prefers-reduced-motion` отключить шиммер и анимации появления.

## Языки

- Три языка: английский (по умолчанию), русский, армянский.
- Адреса: `/` английский, `/ru/` русский, `/hy/` армянский.
- Тексты в отдельных файлах на каждый язык (`messages/en.json`, `ru.json`, `hy.json`), разметка общая.
- Переключатель `EN · RU · HY` в правой части меню-пилюли.
- Армянский пока черновик. Пока его не вычитает носитель языка, страница `/hy/` собирается, но в переключателе её нет (флаг в конфиге, например `HY_ENABLED = false`).
- У `<html>` атрибут `lang` должен совпадать с языком страницы. Для каждой версии свои `title`, `description` и Open Graph-превью (тёмная картинка 1200×630 с именем и должностью), чтобы ссылка красиво выглядела в Telegram и LinkedIn.

## Блоки сверху вниз

1. **Меню-пилюля:** Home, Work, Contact и переключатель языка. Пункта About нет.
2. **Герой во весь экран:** надпись о локации, заголовок «DevOps & Backend Engineer» с акцентом на «DevOps», одна строка о себе, две кнопки: «See my work» (якорь на Work) и «Download CV». Аватаров клиентов нет.
3. **Технологии:** заголовок, одна строка вступления, 12 карточек в сетке `1 / 2 / 4` колонки. Список и подписи в `content.md`. Иконки брать из Simple Icons (лицензия CC0), подложка в цвете бренда с прозрачностью 0.2.
4. **Work (Silver Udochki):** заголовок, вступление, ссылки «All projects» (https://github.com/byterID) и «Live site» (https://silver-udochki.ru). Под ними 4 карточки в сетке 2×2: скриншот, название, одна-две строки, теги и ссылка «View in repo» на раздел README. Отдельных страниц кейсов нет.
5. **Freelance:** заголовок, одна строка, 4 услуги, кнопка в Telegram. Цены не пишем.
6. **Contact:** большой заголовок, кнопки «Telegram» (основная, с шиммером) и «Email». Телефон на сайте не публикуем.
7. **Подвал:** имя, `© 2026`, колонки Navigate (Home, Work, Contact), Project (Repository, Live site), Socials (GitHub, LinkedIn, Telegram).

Блоков с отзывом, опытом и «About» нет: опыт есть в резюме за кнопкой CV.

## Ссылки «View in repo»

Ведут на разделы README в https://github.com/byterID/Silver-Udochki. Модель должна открыть README, найти реальные заголовки разделов и подставить якоря. Если подходящего раздела нет, вести на корень репозитория и пометить `[TODO]`.

## Хостинг и деплой

- GitHub Pages, публичный репозиторий `byterID/byterID.github.io`, адрес сайта https://byterid.github.io.
- Деплой своим workflow в GitHub Actions: `actions/checkout`, установка Node, `npm ci`, `npm run build`, `actions/upload-pages-artifact` с папкой `out`, затем `actions/deploy-pages`. В настройках репозитория источник Pages: GitHub Actions.
- В `out/` положить пустой `.nojekyll`.
- Лимиты GitHub Pages: сайт до 1 ГБ, мягкий лимит трафика 100 ГБ в месяц. Визитка весит примерно от 5 до 20 МБ.
- Свой домен пока не покупаем.
