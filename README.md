# Контекст для сайта-визитки Артемия Гладкова

Папка для модели, которая будет собирать сайт. Здесь факты о владельце сайта и разбор дизайна референса. Тексты на сайте пиши только по этим фактам. Если чего-то нет в файлах, не придумывай, а оставь заглушку `[TODO: ...]`.

## Файлы

- `plan.md`: утверждённый план сайта. Начинай с него.
- `content.md`: готовые тексты на EN, RU и HY (армянский пока черновик).
- `about-me.md`: кто он, где живёт, контакты, языки, формат работы.
- `experience.md`: опыт работы, результаты в цифрах, образование.
- `stack.md`: технологии с пометкой, где он их применял.
- `projects.md`: pet-проект Silver Udochki и что в нём показано.
- `reference-design.md`: дизайн референса andrijaweb.vercel.app (цвета, шрифт, компоненты, порядок блоков).
- `assets/`: резюме в PDF (EN и RU). Они же файлы для кнопки «Download CV»: EN-версия сайта отдаёт английское, RU и HY отдают русское.

## Правила для текстов

- Позиционирование и языки описаны в `plan.md`. Основной язык английский, тексты бери из `content.md`.
- Тон: спокойный, без рекламных слов. Владелец просил тексты «продающие, но не сильно завирающие».
- Не приписывай коммерческий опыт в DevOps. Коммерческий опыт есть в backend на PHP и в системном администрировании. DevOps он изучает на своём проекте.
- Не используй длинные тире в текстах сайта. Ставь запятую, точку или двоеточие.
- Отзывов клиентов и фото клиентов у него нет. Блоки референса с отзывом и аватарами клиентов не заполняй выдуманными людьми.
